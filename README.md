# MDViewer

Windows 용 마크다운 뷰어입니다. 이 저장소는 MDViewer 의 **설치 파일 배포 전용** 저장소입니다 — 소스 코드는 공개되어 있지 않습니다.

## 다운로드

[Releases](https://github.com/SleighMaster99/MDViewer-Releases/releases/latest) 에서 최신 설치 파일(`MDViewer-Setup-x.y.z.exe`)을 내려받아 실행하세요.

- 지원 환경: Windows 10/11 (x64)
- 설치된 앱은 설정의 정보 페이지에서 버튼 한 번으로 새 버전으로 업데이트할 수 있습니다.

## 사용 조건

- **무료 사용** — 개인·업무·상업 목적 구분 없이, 기기 수 제한 없이 사용할 수 있습니다.
- **복제본 배포 금지** — 설치 파일·설치된 파일을 제3자에게 재배포·판매·대여할 수 없습니다. 필요한 사람에게는 이 페이지를 안내해 주세요.
- **개작 금지** — 소프트웨어의 수정·변형·2차적 저작물 작성은 허용되지 않습니다.

상세 조건은 설치 시 표시되는 최종 사용자 사용권 계약(EULA)을 따릅니다.
